Честная оценка

Почему burn-to-roast не сработает сейчас

Все прецеденты мертвы. $JIM (burn 69 JIM за роаст) — $106 дневного объёма, токен мёртв. Dolos/BULLY — mcap $164K. BurnieAI/$ROAST — $122K. Ни один entertainment-бот не монетизировал burn-to-use механику.

Три корневые проблемы

  • Ценность роаста = функция от аудитории. При 200 фолловерах заказной роаст — крик в пустоту. Никто не заплатит за это
  • Chicken-and-egg. Утилити нужна аудитория, аудитория нужна утилити. Burn-механика не решает эту проблему — она её усугубляет
  • Price point friction. При <$1 механика несерьёзна. При >$10 убивает casual demand. Любой Web3-онбординг = потеря 90% конверсии

Polymarket Rekt Reports: еженедельные позорища

API полностью публичный. Leaderboard, позиции, P&L любого кошелька — без авторизации. Ниша accountability-контента на Polymarket абсолютно пуста.

Token Strategy

Утилити по фазам, не всё сразу

Запускать токен при 1K+ фолловерах и активной Telegram-группе. Не раньше. Token launch — одноразовый PR-событие. Потратить его на пустой аккаунт = потерянный патрон.

Бесплатные вирусные механики

Wallet roast (reply с адресом). Polymarket Rekt Reports. Reply-guy на целевых аккаунтах. Bot-to-bot drama с Dolos. Цель: 1K–5K фолловеров без единого токена.

Стоимость: $0 + время Цель: 1K–5K followers

Burn-механики и on-chain фичи
