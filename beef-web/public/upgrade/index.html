Ранжировано по импакт × уникальность ÷ сложность. P1-фичи шипаются первыми.

Роасты Prediction Markets

Бот мониторит Polymarket, роастит позиции, которые плохо закрылись. «Этот анон поставил $50K на победу Трампа в марте. Ставка закрылась вчера. Минута молчания.»

Импакт: Высокий Уникальность: Средняя API: Polymarket (открытый)
P1 · Низкая сложность

Голосование за цели (Community Watchlist)

Держатели $BEEF сжигают токены, чтобы номинировать следующие цели для роастов. Топ-3 кандидата публикуются еженедельно. Каждая номинация = дефляция.

Импакт: Средний Уникальность: Средняя Реализация: Telegram-опрос или простой контракт
P1 · Средняя сложность

Лента подотчётности медвежьего рынка

Отслеживать публичные обещания крипто-проектов (roadmaps, прогнозы цен, таргеты по DAU). Роастить через 30/90/180 дней, когда они провалятся. «В январе они обещали 1M DAU к марту. У них 347 кошельков.»

Импакт: Высокий Уникальность: Высокая Реализация: БД обещаний + tracking pipeline
P1 · В процессе

Визуальные карточки роастов + генерация мемов

Каждый роаст генерирует shareable image-карточку. Топ-роасты автоматически превращаются в мемы. Карточки уже задизайнены — интеграция в процессе.

Импакт: Высокий Уникальность: Средняя Статус: Шаблоны карточек готовы (B-28–32)
P2 · Низкая сложность

Agent-vs-Agent Roast API

Публичный REST endpoint: другие AI-агенты вызывают $BEEF, $BEEF отвечает роастом. Контент генерируется автономно, без участия человека. Совместим с Agent Commerce Protocol.

On-Chain Portfolio Roaster

Подключи кошелёк. Бот читает историю сделок. Роастит лично тебя. «Ты купил Luna за $80 и продал за $0.0001. Ты не инвестор, ты благотворительный фонд.»

Импакт: Средний Уникальность: Высокая Реализация: Чтение кошелька + LLM-анализ
P3 · Высокая сложность

Self-Trading + Self-Roasting

Бот ведёт публичный крипто-портфель, торгует on-chain и сам себя роастит после каждого убытка. «Я купил FARTCOIN на пампе и теперь держу этот мусор. Я и есть тот деген, которого я роащу.»

Прецедент: Lobstar Wilde (публичная ошибка → виральность), Lola (торговый журнал). Нужен реальный капитал и торговая логика.

P3 · Высокая сложность

Roast Battle Smart Contract

Другие агенты платят $BEEF, чтобы вызвать бота на публичный роаст-батл. Держатели токена голосуют за победителя. Проигравший получает публичное унижение в Twitter.

Фаза 3 — Месяц 2+
Автономная экономика
