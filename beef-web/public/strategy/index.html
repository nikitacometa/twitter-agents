Key Insights

01

Reply = 13.5x the weight of a like in X's algorithm. Author reply-back = 75x. A conversation thread = 150x. For a 12-follower account, reply guy is the only viable growth channel.

02

X restricted automated API replies (~Feb 2026). Unsolicited replies via API return 403. Only mention-based replies allowed. Playwright or manual posting required for cold replies.

03

Pattern repetition is a research problem, not an angle problem. The bot has 9 angles already. The real issue: Perplexity always returns the same facts about a token. Solution: thematic lenses that redirect research focus.

04

gpt-image-1.5 can replace 3 separate visual tools. It generates meme formats, data cards, and custom art through one API. Simplifies the pipeline from 3 integrations to 1.

05

Not every post needs a visual. Autonomous roasts: always. Reply guy replies: 50%. Casual: rarely. Over-using images in replies looks like spam.

06

Mid-tier accounts (50K-300K) are better reply targets than mega-KOLs. Less competition in replies, higher chance of author engagement, better follower conversion.

07

Tenor is dead. Shutdown 30 June 2026 (not August), no new API keys since January. Giphy only for GIF reactions (free tier: 100 req/hr).

08

Token launch: milestone-based, not date-based. Trigger: 200+ followers OR a viral moment (50K+ impressions on a single post). Launching to 12 followers wastes liquidity.

Meme Strategy

Three visual channels, one primary tool, context-dependent selection.

Channel Tool When Cost Speed
AI Memes gpt-image-1.5 Autonomous roasts, viral-potential targets ~$0.05/img 5-15s
Template Memes imgflip Premium Quick replies, classic formats $9.99/mo ~1s
Data Cards satori + resvg-js Stats, comparisons, "receipts" $0 ~3s cold

Hybrid Pipeline

For high-value autonomous roasts, generate multiple visuals and let an LLM judge pick the best:

1. LLM generates roast text
|
2. Parallel generation: gpt-image-1.5 meme + imgflip template + satori data card
|
3. LLM-judge evaluates: "which visual best amplifies this roast?"
|
4. Winner attached to tweet, losers discarded

When to use hybrid: autonomous roasts (5/day). Time is not critical, quality matters.

When not to: reply guy replies (10-20/day). Speed matters. Use template meme or text-only.

Self-Review Corrections

Issues found during revision of the original analysis. Factual errors, contradictions, and outdated assumptions fixed.

Factual Corrections

"+178% engagement for images" — Likely from Buffer 2014 study. Outdated. Images boost engagement, but the exact multiplier varies by content type and era. Removed specific number.

"150x author-reply weight" — Misleading. 150x is for a full conversation thread, not a single reply. Single reply = 13.5x a like. Fixed in analysis.

"Days 1-3: no replies at all" — This warming-up advice is for brand-new accounts. @0xBeefer is ~2 weeks old with ~25 posts and X Premium. Can start with 10 replies/day immediately.

Priority Corrections

Reply guy pipeline was listed as "5-7 days" — but /roast-tweet is already implemented. Core routing works. Remaining: auto-discovery + scheduling (2-3 days).

Media upload was listed as "2-3 days" — agent-twitter-client already supports mediaData. Actual work: interface extension + buffer passthrough (1 day).

Data cards before memes — Reversed. Memes have higher viral potential for a roast bot. Data cards are nice-to-have, memes are growth drivers.

Strategic Corrections

3 separate visual tools → 1 primary tool. gpt-image-1.5 can generate meme-format images, data card aesthetics, and custom art. One API covers 80% of use cases. imgflip for speed-critical template memes only.

Tenor API is dead. Shutdown timeline: no new keys since Jan 2026, full shutdown 30 June 2026. Giphy is the only viable GIF source.
