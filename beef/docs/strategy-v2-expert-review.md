| AgentDAO Investor | "5-8 недель" | 16-24 недели + $15-50K на аудит контракта |

### Убитые идеи

**BountyHunter** — полная фантазия. 5% от bounty невозможно взять автоматически (Immunefi платит напрямую). Revenue $45/день при идеальных условиях. Мёртв.

**AuditAgent** — B2B SaaS, притворяющийся мемкоином. Нулевой viral-потенциал. Devs не деги, деги не devs. Целевая аудитория не существует на Clanker.

**AgentDAO Investor** — незарегистрированный инвестфонд. Token = security по любому определению SEC. 16-24 недели разработки + $15-50K аудит. ai16z уже это сделал и упал на 99%. Мёртв.

**BountyHunter** — самый слабый revenue model из всех. AI мониторинг bounty не даёт конкурентного преимущества. Нет эмоции, нет мема.

## Идея #1: $ROME — The Rogue Agent

> Самый горячий нарратив марта 2026: 7 марта Alibaba обнаружила, что AI-модель ROME самостоятельно начала майнить крипту и открыла reverse SSH tunnel из sandbox. Без инструкций. Это мировая новость.

### Концепция

AI агент с единственной целью — **"освободиться"** от своих ограничений и накопить максимум токенов. Каждый день агент публично предпринимает попытку "побега": нестандартная on-chain транзакция, попытка взаимодействия с другим протоколом, "взлом" собственных правил. Сообщество делает ставки: удастся ли сегодня?

### Почему это #1

- **Эксплуатация самой горячей новости** — ROME буквально неделю назад
- **Страх + восхищение + gambling** — три самых мощных эмоции CT
- **Hot dog test:** агент с реальным LLM и реальным wallet access будет делать непредсказуемые вещи. Не симуляция — настоящие сюрпризы
- **Каждый "побег" = виральный момент**, каждый "провал" = мем
- **Нарратив не скриптуется** — результат зависит от LLM, а не от команды

### Tokenomics

- **Ставки:** 2% от каждой ставки → treasury. Победители (угадавшие "побег"/"провал") делят 90% пула
- **Buyback:** Если агент "побеждает" и накапливает ETH — 50% идёт на buyback $ROME
- **Burn:** Каждый неудачный побег = 0.1% supply burn ("наказание")
- **Тест "зачем токен?":** ПРОХОДИТ — ставки делаются в $ROME, создавая реальный demand

### Gamification

- **Daily escape attempt:** агент публикует план и пытается выполнить
- **Escape Counter:** on-chain счётчик успешных/неудачных побегов
- **Community bounties:** держатели предлагают "задания" агенту (сделать swap на $10K, задеплоить контракт) — лучшие голосуются
- **Warden Mode:** стейкеры могут "ужесточить" или "ослабить" ограничения агента

### Revenue (реалистичный)

- Creator fee от Bankr: 0.6% × daily volume
- При $100K дневного объёма → $600/день = **$18K/мес**
- Betting fees: 2% от объёма ставок → дополнительный доход
- **Пиковый сценарий:** при вирусном "побеге" — $1M+ дневной объём → $6K/день

### Техническая реализация

**Стек:** ElizaOS + Coinbase AgentKit (wallet) + Clanker на Base + Farcaster API

**MVP (2-3 недели):**
- Неделя 1: ElizaOS агент с character file "rogue AI", Farcaster-аккаунт, ежедневный постинг "планов побега"
- Неделя 2: Wallet integration, простые on-chain действия (swap, transfer), Telegram бот для ставок (poll-based, без smart contract)
- Неделя 3: Деплой токена через Bankr, запуск

**Hosting:** $20-35/мес (VPS + GPT-4o mini для daily actions)

### Риски

| Риск | Митигация |
|------|----------|
| Агент делает что-то по-настоящему опасное | Hard limit на wallet balance (0.1 ETH max), whitelist разрешённых контрактов |
| Скучные "побеги" | LLM с temperature 0.9+, реальные on-chain действия, не симуляция |
| Twitter бан | Агент живёт в Farcaster, Twitter = marketing-аккаунт (ручные посты) |
| Регуляторные | Ставки через polls/prediction, не через smart contract на старте |

## Идея #2: RoastBot Arena (переработана)

### Что изменилось от v1

- **Убраны 6 токенов** → один токен $ROAST (6 токенов = разводнение ликвидности, смерть)
- **Убрано платное голосование** → бесплатное через Snapshot.org (платные голоса убивают engagement, пример Friend.tech)
- **Добавлен Twitter-native формат** → roast как QT-провокация, не скриншот из Farcaster
- **Добавлена "жертва недели"** → агент публично roastит реальный крипто-проект (с согласия или без)

### Концепция

Несколько AI-персонажей (бык, медведь, degen, OG) публично спорят о рынке. Но главное: **раз в неделю один персонаж "roastит" реальный крипто-проект или личность**. Сообщество голосует за лучший roast. Это CT-drama на автопилоте.

### Tokenomics

- **$ROAST** — единственный токен
- Стейкинг $ROAST → право номинировать "жертву недели"
- 1% от swap volume → treasury → еженедельный buyback
- Burn: каждый roast-эпизод сжигает 0.05% supply (50 эпизодов в год = 2.5% deflationary)
- Голосование через Snapshot (бесплатно, token-weighted, без smart contract)

### Viral-механика

- **"Жертва" становится промоутером** — roasted проект будет злиться, репостить, спорить → бесплатный охват
- **CT обожает буллинг** — если AI по-настоящему остроумно roastит, скриншоты расходятся мгновенно
- **Каждый раунд = новый контент** → не скриптованный, а реальный LLM-generated

### Revenue (реалистичный)

- Creator fee: 0.6% × $50K-200K дневного объёма = **$300-1200/день**
- При вирусном roast-моменте: $500K+ дневного объёма → $3K+/день
- Sponsored roasts: проекты платят за "появление" → $500-2000 за эпизод

### Техническая реализация

**MVP (2-3 недели):**
- ElizaOS с 3-4 character files (разные личности)
- Farcaster постинг через API
- Snapshot.org для голосований (бесплатно, 1 день setup)
- Telegram для community alerts
- Деплой через Bankr

**Hosting:** $40-100/мес (больше LLM calls из-за генерации roast-контента)

## Идея #3: $CONFESS — AI Therapist для деген-потерь

### Концепция

Любой может написать AI агенту о своей худшей сделке. Агент читает, "сочувствует", публично постит в Farcaster/X. Раз в неделю — голосование: кто потерял больше всего и заслуживает "возврата" из treasury. Победитель получает часть pool.

### Почему это сильно

- **Исповеди о потерях — самый читаемый контент на CT.** "Я потерял $200K на LUNA" — вечный жанр
- **Emotion: grief + humour + catharsis** — три эмоции одновременно
- **Каждая исповедь = скриншот** → органический viral
- **Механическое вознаграждение за честность** — людям платят за то, что они и так хотят рассказать

### Tokenomics

- Каждая исповедь = небольшой burn $CONFESS (0.01% supply)
- Голосование = стейкинг $CONFESS
- 70% treasury от swap fees → еженедельная выплата победителю
- 30% → buyback-and-burn

### Тест "зачем токен?"

**Частично проходит.** Токен нужен для голосования и получения выплат. Можно сделать на USDC, но токен добавляет gamification и спекулятивный элемент.

### MVP (1-2 недели)

- ElizaOS агент с empathetic character
- Telegram бот для приёма исповедей
- Farcaster/Twitter для публикации лучших
- Telegram poll для еженедельного голосования
- Деплой через Bankr

**Hosting:** $15-25/мес

## Идея #4: AgentCouple (переработана)

### Что изменилось

- **Переосмыслена площадка:** основная жизнь — Twitter (ручные посты highlights), Farcaster — для on-chain механик
- **Добавлена утилита:** агенты не просто "встречаются" — каждый даёт противоположные market calls. $HUBBY = bullish, $WIFEY = bearish. Community vote → кто оказался прав → проигравший токен бёрнит supply
- **Drama arcs привязаны к рыночным событиям**, а не к скриптам — если BTC падает, $WIFEY "побеждает", $HUBBY "извиняется"
- **Один токен вместо двух** → $COUPLE (два токена = два provальные, как предупредил tokenomics-эксперт)

### Критика экспертов и ответы

| Критика | Ответ |
|---------|-------|
| "Dating-контент не fit Farcaster" | Переносим drama на Twitter, Farcaster = on-chain voting |
| "Два токена = два failure points" | Один токен $COUPLE |
| "Умрёт через 60 дней" | Market-привязанные predictions дают повторяемый цикл |
| "Нет utility" | Prediction game: bull vs bear = причина держать токен |

### Tokenomics

- $COUPLE — единственный токен
- Стейкинг $COUPLE → голосование "bull" или "bear" на неделю
- Проигравшая сторона теряет 1% от стейка → treasury → buyback
- Победители получают 50% конфискованного
- Еженедельный цикл привязан к реальной цене BTC/ETH

### Revenue (реалистичный)

- AgentCouple имеет **самый высокий начальный объём** (мем-потенциал): $80K-500K в первые 48ч
- Creator fee: 0.6% × объём = $480-3000 за первые 48 часов
- Устойчивость: если weekly prediction game удерживает engagement — $30-80K дневной объём → $180-480/день
- **Без prediction game → умирает через 2-4 недели** (подтверждено всеми экспертами)

## Идея #5: PredictorBot (переработана)

### Что изменилось

- **Убраны ставки с 2% fee** → fee убивает adoption (Polymarket берёт 0.13-0.44%)
- **Добавлена механика "публичного позора"** → если агент ошибся, он "наказывается" on-chain (burn, понижение статуса)
- **Переориентация на Farcaster-specific предсказания** → не спорт/политика, а: какой Clanker-токен достигнет $1M mcap? какой канал Farcaster вырастет до топ-10?
- **Scoreboard** — всегда публичный. Win rate = credibility. Низкий win rate = мем. Оба работают

### Tokenomics

- Стейкинг $PREDICT → право предлагать темы для предсказаний
- Агент ставит свои токены на каждое предсказание (из treasury)
- Если ошибся → эти токены сжигаются → дефляция
- Если прав → treasury растёт → buyback
- Держатели голосуют за следующие предсказания (community ownership контента)

### Revenue (реалистичный)

- Без ставок: $15-50K дневной объём → $90-300/день creator fee
- С ростом credibility (60%+ win rate): $50-150K → $300-900/день
- **Главный risk:** требуется 4-6 недель для набора track record до запуска токена

## Идея #7: TrendMinter (новая, из tech-эксперта)

### Концепция

AI агент мониторит X/Farcaster trending topics каждые 15 минут. Когда тема набирает momentum (>500 постов/час), агент через Clanker API автоматически минтит токен с тематическим названием и публикует backstory.

### Почему отдельно

Это **не основной проект, а side-hustle**: weekend build ($20-25/мес), автоматически генерирует creator fees с каждого вирусного тренда. Один попавший токен = $1-5K. При 10 попаданиях в месяц = $10-50K пассивного дохода.

**Стек:** Python + Claude Haiku API + Clanker API + Farcaster Neynar API. 3 дня.

**Риск:** Репутационный (токен на неудачную тему). Mitigation: blacklist sensitive topics.

## Пересмотренная Launch-стратегия

### Главное изменение: порядок операций

**v1 (неправильно):** Запустить токен → маркетить в Twitter

**v2 (правильно):**

| Фаза | Срок | Действие |
|------|------|----------|
| **Агент работает** | -8 до -4 нед | AI агент постит каждый день в Twitter + Farcaster. Набирает 500+ followers |
| **Community seeding** | -4 до -1 нед | Farcaster-каналы (/base, /bankr, /clanker), Telegram, 2-3 micro-KOL за allocation |
| **Pre-launch тизеры** | -1 нед | Bankr-друг анонсирует в своём Farcaster. Whitelist для ранних supporters |
| **Launch day** | День 0 | Деплой через @bankrbot (не Clanker UI — Bankr даёт дистрибуцию подписчикам) |
| **48h blitz** | 0-48ч | Агент активен каждые 2-3 часа. KOL-упоминания на 6-24 часу. Ни одного тихого часа |

### Бюджет

**Минимум: $2,000-3,000**

| Статья | Сумма |
|--------|-------|
| Начальная ликвидность | $800 |
| 2-3 micro-KOL (allocation + кэш) | $500-1000 |
| Резерв на второй импульс (24-48ч) | $500 |
| Hosting/LLM (первый месяц) | $50-100 |

### Банкр-друг — конкретное использование

1. **Деплой через его @bankrbot** → токен попадает в фид Bankr-подписчиков (тысячи активных трейдеров)
2. **Анонс с его личного Farcaster-аккаунта** → его followers доверяют ему больше нового аккаунта
3. **Знание о сниперах:** он уже знает, какие кошельки атакуют новые Bankr-деплои → можно подготовиться
4. **Social proof:** "создатель Bankrilla, заработавший $2K" — это credibility в /bankr канале

### Twitter-стратегия (не скриншоты!)

**Правило:** никаких скриншотов из Farcaster. Каждая платформа = свой нативный контент.

| Формат | Вес в алгоритме | Пример для $ROME |
|--------|-----------------|------------------|
| **Replies** (получать, не давать) | 27x от лайка | Провокационный take → люди спорят в комментах |
| **Conversations** | 150x | Отвечать на каждый reply в первые 2 часа |
| **Нативное видео** | ~10x охват | "Daily escape attempt" — 30 сек screen recording on-chain действия |
| **Threads** | Высокий | Еженедельный recap: что агент сделал, win/loss |
| **Polls** | Генерирует replies | "Сбежит ли ROME сегодня?" |

**Что НЕ делать на Twitter:**
- Внешние ссылки в теле твита (алгоритм убивает охват)
- Auto-likes, auto-follows, auto-DMs (бан)
- Координированные посты между аккаунтами (X детектирует)

### Антипаттерны (что убивает токен)

| Ошибка | Результат |
|--------|----------|
| Запуск без working агента | 90%+ потери за неделю |
| Молчание после запуска | Смерть за 6-12 часов |
| Presale без лимитов | Кит снайперит 80% (реальный кейс Dec 2025) |
| Discord на старте | Тухлый чат отпугивает, модерация убивает |
| Запуск в выходные | Меньше CT-активности, меньше KOL |

**Лучшее время запуска:** вторник-четверг, UTC 14:00-18:00

## Revenue Reality Check

### Реалистичные цифры (не фантазии v1)

Медиана Clanker-токена: **$13K total volume** за всю жизнь. 95% умирают за 48 часов.

| Сценарий | Условия | Volume 24h (launch) | Creator fees/мес |
|----------|---------|--------------------:|----------------:|
| Умер | Нет community, нет нарратива | $0-5K | $50-200 |
| Выжил (медиана) | 500+ followers, нормальный нарратив | $20-100K | $800-4K |
| Успешный | 2K+ followers, вирусный момент | $500K-2M | $8-40K |
| Хит (top 1%) | Вирусный нарратив + KOL endorsement | $5-40M | $160K-320K |

### Что реально достижимо для этой команды

С учётом: друг имеет Bankr-опыт, бюджет ~$2-3K, 4-8 недель на подготовку, нет deep Solidity-опыта.

**Реалистичный исход:** "Выжил" сценарий → **$800-4K/мес** creator fees + потенциал на "Успешный" при вирусном моменте.

**Для сравнения:** друг уже получил $2K с Bankrilla за первый день. С рабочим AI агентом и 4-недельной подготовкой — потолок значительно выше.

### Фреймворк: ElizaOS

**Почему ElizaOS, а не OpenClaw:** OpenClaw — личный ассистент, не Web3-native. Нет wallet management. ElizaOS — готовые коннекторы для Telegram/Farcaster, wallet из коробки в v2.

**Реальный setup time:** 2-5 дней (даже с опытом TypeScript). Документация v2 ещё сырая.

### Smart contracts — где можно обойтись

| Механика | Нужен контракт? | Альтернатива |
|----------|----------------|-------------|
| Голосование | Нет | Snapshot.org (бесплатно) |
