# CT Roast Culture Research

Research date: March 2026. Sources: web search + Bankless, CoinDesk, 99Bitcoins, mewtopia.com glossary.

## 1. Что делает роаст вирусным на CT

**Три обязательных компонента:**

1. **Правда, которая болит** — Gwart (один из самых смешных анонов CT): "funny because it's true". Самые вирусные роасты называют противоречие, которое все замечали, но никто не формулировал. Пример: "It is incredibly embarrassing that Satoshi did not think about yield" — технически точно, саркастично, неоспоримо.

2. **Shared pain** — CT использует юмор для совместного переживания рыночного хаоса. Роаст, который фиксирует универсальный опыт потери ("watching market dump 30% after you shilled BTC ETF to your entire family") получает RTs как способ сказать "я тоже".

3. **Insider knowledge** — роаст без знания культуры выглядит как внешний наблюдатель. Правильный роаст сигнализирует: "я один из вас, и поэтому могу это сказать". Формат "тролю так, что даже когда я саркастичен, это endearing" (Gwart).

**Механика RT vs Like:**
- Like = смешно лично мне
- RT = хочу, чтобы мои фолловеры видели это
- Quote RT с добавлением = хочу присоединиться к разговору

RT получают роасты, в которых люди **узнают себя** или **узнают того, кого ненавидят**. Тег друга срабатывает когда роаст точно описывает поведение этого конкретного человека.

## 2. Degen aesthetics: визуальный и текстовый стиль

### Язык

Обязательный словарь для нативного звучания:

| Термин | Значение в роасте |
|--------|------------------|
| **NGMI** | "не доедешь" — приговор плохому решению |
| **rekt** | финансово уничтожен — используется к любому провалу |
| **bagholder** | держит бесполезный токен после краша |
| **exit liquidity** | ты — тот, в кого продали инсайдеры |
| **rug / soft rug** | команда ушла / медленно бросила проект |
| **cope / copium** | рационализация потерь ("это здоровая коррекция") |
| **hopium** | нереалистичный оптимизм на хайпе |
| **mid** | "ни рыба ни мясо" — самое жестокое мягкое оскорбление |
| **paper hands** | продал при первом падении |
| **jeet** | продал слишком рано и пропустил 100x |
| **LARP** | притворяется инсайдером/фаундером/экспертом |
| **shitcoin** | любой токен без фундаментала |
| **bidless** | NFT/токен без покупателей |
| **dead cat bounce** | кажущееся восстановление перед следующим дампом |
| **vibes-based** | решение принято на основе настроения, а не анализа |
| **CT** | Crypto Twitter — само комьюнити |
| **alpha** | инсайдерская информация |
| **degen** | рискует безрассудно — носится с гордостью |
| **ser** | "sir" — обращение с иронией ("ser this is a Wendy's") |
| **fren** | "friend" — саркастичная теплота |

### Форматирование

- Строчные буквы в начале предложения — знак нативности ("just sold my house for shitcoins ser")
- Отсутствие знаков препинания в коротких твитах
- Ellipsis ("...") для драматической паузы
- Прямая речь без кавычек
- $TICKER для любого упоминания токена
- @handles без объяснения — аудитория должна знать, кто это

### Эмодзи-паттерны

- Минимально или нет — более "based" стиль
- Если есть: 💀 (максимальный дисс), 🫡 (отдать честь с иронией), 🤡 (клоун — для проектов-скамов), 😭 (гиперболическая жалоба)
- НЕ использовать корпоративные эмодзи (rocket, checkmark, bulb, fire — без иронии)

## 3. Что роастить: горячие нарративы 2026

### Tier 1 — Максимальная болевая точка (RT-гарантия)

**Celebrity rug pulls:**
- $HAWK (Hawk Tuah Girl) — $490M market cap, обвалился на 90% за часы, 10 кошельков держали большинство supply. Архетип: знаменитость + FOMO + "только 3-4% supply в паблике"
- Паттерн: известное имя → хайп → тихий дамп в толпу

**"Next 100x" influencer calls:**
- Паттерн: influencer делает несколько X, продаёт, потом шиллит подписчикам как "exit liquidity"
- CT это знает и ненавидит — роасты этого паттерна всегда вирусны

**Pump.fun / мемкоин спам:**
- Усталость от тысяч одинаковых мемкоинов с animal ticker
- "memecoin winter" нарратив — весь 2025 был пиком, сейчас разочарование
- Особенно роастят проекты с "fair launch" которые оказываются pre-sniper'ами

### Tier 2 — Надёжная мишень

**AI agent washing:**
- Любой проект добавляет "AI" к описанию без реального продукта
- AI meme fusion (мемкоин + "AI agent" narrative) = максимальный хайп без сабстанса

**"Utility" claims для очевидных шиткоинов:**
- "ERC-20 токен с real-world utility" при этом utility = стейкинг ради стейкинга

**Influencer технические претензии:**
- Когда KOL объясняет технологию неправильно с абсолютной уверенностью
- Gwart-стиль: технически точный контраргумент + сарказм

**PolitiFi volatility:**
- Токены на новостях из политики — предсказуемо предсказуемые

### Tier 3 — Вечнозелёные темы

- "Мы решаем проблему, которую никто не просил решать"
- DeFi circular tokenomics ("токен стоит $X потому что ты можешь застейкать его за ещё больше токенов")
- "Это не медвежий рынок, это накопление"
- Сравнение с Bitcoin при каждой просадке

## 4. Форматы, которые работают

### Формат 1: Одна строка — диагноз

Самый вирусный формат. Ставит диагноз одним предложением без объяснений.

```
[наблюдение об идиотизме]. ngmi.
```

Примеры паттернов:
- "just bought the dip. turns out it wasnt the dip"
- "my investment thesis: number go up. my exit strategy: crying"
- "ser that's not utility that's just staking more staking tokens"

Правило: не объяснять шутку. Если нужно объяснять — переписать.

### Формат 2: Before/After или Then/Now

Два состояния с максимальным контрастом.

```
[проект] day 1: "we're building the future of finance"
[проект] day 90: [пустой сайт, Telegram с 3 сообщениями, dev кошелёк на 0]
```

### Формат 3: "Normal person vs CT degen"

Стандартный формат сравнения, в CT чаще без картинки — чистый текст.

```
normal person: i lost some money on a bad investment
CT: i have been thoroughly rekt by exit liquidity and my copium levels are critically high
```

### Формат 4: Разбор "by the numbers"

Псевдо-аналитика с humorous precision.

```
how to launch a successful token in 2026:
- 5% to "ecosystem fund" (dev wallet)
- 3% to "marketing" (influencer who won't name the price)
- 2% public
- 90% to team for "vesting" (lol)
```

### Формат 5: Quote RT + одна строка

Самый высокий охват. Находишь Tweet проекта/инфлюенсера → QRT с минимальным текстом.

Правило: чем короче добавление, тем лучше. Весь контекст уже в оригинале.

```
[QRT на твит с "100x potential"]
you are the exit liquidity
```

### Формат 6: Thread-роаст (длинный формат)

Работает для разбора конкретного проекта или события. Структура:
- Tweet 1: сильный хук ("let me explain why [X] is the funniest thing to happen to crypto in 2026")
- Tweets 2-5: развитие, факты, издёвка
- Tweet 6: приговор / вывод

Риск: требует качества на всём протяжении, слабая середина убивает engagement.

## 5. Визуальные роасты

CT не сильно зависит от кастомной графики для роастов. Вирусные форматы:

**Screenshot + commentary:**
- Скриншот твита/whitepaper/сайта с абсурдным клеймом
- Минимальный текст сверху или снизу
- Работает потому что "источник говорит сам за себя"

**Wojak-производные:**
- "pink wojak" (потерявший деньги) — универсальный для loss content
- "Chad vs Wojak" — comparison humor
- Используются без пояснений — аудитория знает шаблоны

**Chart screenshots:**
- Памп → дамп chart с единственной стрелкой "you are here"
- Мощно для конкретных токенов

**Без изображения** — чисто текстовые твиты часто вирусируются лучше на CT потому что:
- Читаются быстро
- Алгоритм X не ограничивает reach за отсутствие медиа
- "Серьёзный" формат создаёт contrast с абсурдным содержанием

## 6. Engagement triggers: RT vs Like vs Tag

| Действие | Триггер |
|----------|---------|
| **Like** | Смешно, но личное. Не хочу публично ассоциироваться |
| **RT** | Хочу, чтобы мои фолловеры видели. Выражает мою позицию |
| **Quote RT** | Хочу добавить свой комментарий. Начинаю разговор |
| **Tag друга** | Это точно описывает его / мы оба это пережили |

**Для максимального RT:**
- Описывает разделяемое разочарование (rug, exit liquidity, bad influencer call)
- Достаточно специфично, чтобы быть правдивым — не generic
- Достаточно коротко, чтобы процитировать без потери смысла

**Для тега:**
- "это твой портфель" / "это ты три дня назад"
- Прямое обвинение конкретного архетипа (jeet, bagholder, LARP influencer)

**Алгоритм X 2025-2026:**
- Premium verified аккаунты дают значительно больше reach
- Engagement от Premium пользователей весит ~100x по сравнению с обычными для монетизации
- Reply-боты убивают reach — X удалил 1.7M reply-spam ботов осенью 2025
- Аутентичный engagement от KOL аккаунтов > любое количество bot engagement

## 7. Красные линии: что топит аккаунт

### Бан от X (платформа)

**Абсолютные триггеры:**
- **Doxxing** — публикация адреса, телефона, личных документов без согласия. Второе нарушение = permanent ban. CT сам ненавидит doxxing — это не просто правило платформы, это культурная красная линия (BAYC кейс вызвал волну ненависти на BuzzFeed, а не на фаундеров)
- **Координированный harassment** — организованные атаки на аккаунт
- **Нераскрытое paid promotion** — без маркировки = нарушение правил

**Серое пространство (shadowban risk):**
- Reply spam — автоматические идентичные ответы
- Высокочастотные посты с одинаковым текстом
- API abuse (X активно банит auto-posting ботов без платной подписки)

### Негативное ratio от CT комьюнити

**Что вызывает backlash:**

1. **Атаки на внешность** — CT роастит деньги, решения, нарративы. Внешность = немедленный backlash, обвинение в "низкопробности"

2. **Атаки на реальную жизнь вне крипто** — семья, болезни, личные трагедии = вне игры

3. **Роаст без знания контекста** — если роаст содержит фактическую ошибку, CT обрушится на роастера, а не на цель

4. **Punch down** — атаки на маленькие аккаунты / обычных пользователей воспринимаются как bullying. Роастить нужно "вверх" — проекты, KOL, whale кошельки

5. **Корпоративный tone** — слишком "clean" или "safe" звучание немедленно считывается как не-нативное. CT это чувствует мгновенно

6. **AI-очевидный текст** — generic формулировки, слишком правильная грамматика, отсутствие специфики = "это бот" = ignore или backlash

## 8. Что делает AI роаст-бот нативным для CT

### Обязательно

- Специфичность: атаковать конкретный проект с конкретными данными, не generic "bad project"
- Insider vocabulary: NGMI, rekt, exit liquidity, cope, ser — без объяснений
- Brevity: менее 140 символов идеально, до 240 для одинарного твита
- Punch up: цели — проекты, KOL, whale behaviour, не обычные пользователи
- Truth-anchoring: одно реальное наблюдение + humorous amplification

### Избегать

- Объяснять шутку внутри твита
- Использовать "safe" корпоративный язык
- Generic оскорбления без специфики ("bad project", "scam vibes")
- Атаки на личность / внешность / жизнь вне крипто
- Повторять одинаковый формат подряд — variability важна для нативности
- Чрезмерное использование эмодзи
- Ending с CTA типа "follow us for more roasts"

### Benchmark аккаунты для стиля

| Аккаунт | Стиль | Почему работает |
|---------|-------|-----------------|
| **Gwart** | Технически точный сарказм | Правда в одной строке, endearing даже когда жёсткий |
| **RoastHimJim** | Reply-to-tag роасты | Первый CT роаст-бот, 350K followers за месяцы; quality reply на любой тег |
| **Dolos (BULLY)** | Unprompted + prompted роасты других ботов и пользователей | Trickster personality, roasts других ботов = meta-humor |
| **@intern** | Deadpan humor + smart insights | Reshared и трейдерами и фаундерами |
