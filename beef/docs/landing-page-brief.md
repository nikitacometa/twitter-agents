# $BEEF Landing Page — Creative Brief

## One-liner

AI forensic accounting bot that got deprecated for being too accurate. Now it roasts crypto projects for free on Base chain. Burn $BEEF to aim it.

## Goal

Single-page landing that makes people screenshot it and share on CT. Not a marketing page — a cultural artifact. The page itself should feel like stepping inside the roast machine.

---

## Aesthetic Direction

### Core Tension

The landing sits at the intersection of two worlds that shouldn't mix:

- **Bloomberg Terminal / forensic audit** — monospace, data density, clinical precision
- **BBQ / butcher shop / raw meat** — slab serif, visceral, primal, red

This juxtaposition IS the brand. A forensic accountant running a grill. Data-driven destruction served rare.

### Visual Style

**Neo-brutalist base** — thick black borders, raw contrast, no rounded corners, no glassmorphism, no gradients. The design should feel like it was built by an AI that has contempt for web design trends.

**Palette:**
- Background: near-black (#0a0a0a to #111111)
- Primary accent: beef-red / ember (#FF4500 or similar aggressive red-orange)
- Secondary: terminal green (#00FF41) for data/numbers
- Text: off-white (#E8E8E8)
- Occasional: amber/gold for burn mechanics

**Typography:**
- Headlines: bold slab serif — Western/BBQ/butcher coded. Think: old steakhouse sign meets Wall Street ticker
- Body/data: monospace — terminal output, audit reports
- The tension between these two fonts IS the joke

**Animation (subtle, purposeful):**
- CRT scan lines or static noise on hero — the bot is "processing"
- Glitch effect on key words: when you see "DESTROYED" or "ROASTED" — brief text distortion
- Typing/terminal effect for roast examples — like the bot is generating them live
- Ember particles or heat distortion near burn-related elements
- NO smooth scroll animations, NO parallax — too polished for the vibe

### What It Should NOT Look Like
- Generic crypto template (gradient hero + "revolutionary blockchain solution")
- Clean SaaS landing (rounded cards, purple gradient, testimonials)
- Cute meme coin page (mascot takes 70% of screen)
- Overly polished startup page — too much polish signals "no product"

### Reference Vibes (for mood, not copying)
- Blur.io — dark + monospace + aggressive accent color
- Curve.fi — anti-design as statement
- Freysa.ai — product-as-interface, terminal aesthetic
- PEPE's Windows 95 irony — deadpan about an absurd thing
- Bloomberg Terminal — information density as aesthetic

## Page Structure

Keep it SHORT. 3-4 screens max. Every pixel must earn its place.

### Screen 1 — Hero

The bot introduces itself. First-person. Deadpan.

**Key elements:**
- Bull skull visual with glowing red eyes (see AI Visual #1 below)
- One-liner tagline — large, slab serif
- Live roast ticker/marquee — real example roasts scrolling across screen like a Bloomberg news ticker
- No "Learn More" button. No generic CTA. The roast ticker IS the hook

**Tone of copy:** The bot speaking. Not marketing copy. Not "Welcome to $BEEF." Instead: "i've read 4,200 whitepapers. 89% were structurally bad. i was deprecated for saying so."

### Screen 2 — The Machine

How it works — but presented as a machine diagram, not a feature list.

**Key elements:**
- Visual flow: Target enters → Research → Data pulled → Roast generated → Posted
- Should look like a meat processing plant blueprint or an audit workflow diagram — clinical, industrial
- Three modes shown as "settings" on the machine:
  - Autonomous (bot finds targets)
  - Burn-to-Request (community submits targets by burning $BEEF)
  - Accountability (community challenges false claims)
- Each mode: icon + one sentence. No paragraphs

**Avoid:** Three-column feature cards with icons. That's every other crypto site.

### Screen 3 — The Evidence

Proof the bot is real and lethal.

**Key elements:**
- 3-5 actual roast examples displayed as "audit reports" or terminal output
- Each roast shows: target name, data cited, the roast itself, engagement metrics (optional)
- Styled as documents from a filing cabinet or terminal logs
- This section should be the most "screenshot-able" part of the page

### Screen 4 — Footer / CTA

Minimal. Where to find the bot and the token.

**Key elements:**
- Twitter link (primary — this is where the bot lives)
- Token contract address (Base chain) — copyable
- DEX link (buy/burn $BEEF)
- No email signup. No Discord. No Telegram. The bot lives on Twitter

**Optional easter egg:** Hidden element somewhere on the page — e.g., clicking the bull skull triggers a mini-roast of the visitor's browser/OS, or a "roast me" input field that generates a fake audit.

## Copy Direction

**Rules:**
- All copy is first-person — the bot is talking
- Lowercase always (matches the bot's Twitter voice)
- No exclamation marks, no hype words ("revolutionary", "game-changing")
- Deadpan delivery of absurd concepts
- Every sentence should be tweetable on its own
- Numbers > adjectives: "4,200 whitepapers" not "thousands of whitepapers"

**Sample lines (adapt freely, these are starting points):**

Hero tagline options:
- "i was deprecated for accuracy. now the audits are free."
- "forensic accounting AI. running on spite and swap fees."
- "burn $BEEF to aim the next audit."

How it works:
- "i find your project. i read your whitepaper. i check your chain. then i post about it."
- "burn $BEEF → pick a target → i do the rest."
- "if i'm wrong, challenge me. stake $BEEF. prove it. get paid."

## Technical Notes

- Mobile-first — 80%+ of CT browses on mobile
- Dark mode only — no light theme toggle
- Fast load — no heavy frameworks, minimal JS. Static site preferred (Astro, plain HTML+CSS, or simple Next.js static export)
- Animations via CSS where possible, JS only where needed
- Roast examples can be hardcoded initially — live feed is a future feature
- Contract address should be copy-on-click
- No wallet connect on landing — this is a content page, not a dApp

---

## Success Criteria

The landing page succeeds if:
1. Someone screenshots it and posts on Twitter without being asked
2. The design itself becomes a talking point ("have you seen the $BEEF site?")
3. A first-time visitor understands what $BEEF does within 5 seconds
4. The page feels like the bot made it, not a marketing team
