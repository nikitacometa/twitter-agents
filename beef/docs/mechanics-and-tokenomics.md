## Концепт

**AI-бот, который роастит крипто-проекты. Сжигай $BEEF чтобы навести его на цель.**

Один бот. Один токен. Три режима взаимодействия.

---

## Три режима работы

### Режим 1: Автономный роаст (60-70% контента)

Бот самостоятельно мониторит:
- Новые запуски токенов (DexScreener, CoinGecko)
- Крипто-новости (RSS, Twitter trending)
- On-chain события (крупные трансферы, rugpull'ы)

Находит интересную цель → генерирует роаст с реальными данными → постит.

**Зачем:** бот генерирует контент даже при нулевой аудитории. Не зависит от пользователей. Каждый роаст — потенциальный вирусный момент.

### Режим 2: Burn-to-Roast (после запуска токена)

1. Пользователь сжигает X $BEEF (минимальный порог)
2. Указывает цель (проект, токен, кошелёк)
3. Больше сжёг = выше в очереди
4. Бот генерирует роаст с реальными данными о цели
5. Постит в Twitter + Farcaster

**Зачем:** каждый запрос = burn supply. Механическая deflation.

### Режим 3: Challenge / Accountability (Phase 2)

1. Бот постит роаст с ошибкой (ложные данные)
2. Любой $BEEF holder стейкает → подаёт challenge
3. Комьюнити голосует на Snapshot (off-chain, бесплатно)
4. Успешный challenge → стейкер получает reward из treasury
5. Неуспешный challenge → стейк сжигается

**Зачем:** trust loop. Бот старается быть точным, комьюнити проверяет.

## Токеномика

### Потоки value

| Действие | Эффект на $BEEF |
|----------|----------------|
| Burn-to-roast запрос | Supply сжигается |
| Неуспешный challenge | Стейк сжигается |
| Swap на DEX | 0.684% fee → creator |
| Вирусный контент → новые юзеры | Buy pressure |
| Успешный challenge | Treasury → challenger (redistribution) |

### Flywheel

Смешной роаст → скриншот → вирус → новые юзеры → burn-to-roast → deflation → рост цены → больше внимания → больше роастов.

### Зачем покупать $BEEF

1. **Навести бота на цель** — burn-to-roast
2. **Заработать на challenges** — нашёл ошибку = profit
3. **Спекуляция** — supply постоянно сжигается
4. **Governance (будущее)** — голосование за фичи

### Treasury

Пополняется:
- % от burn'ов (configurable)
- Неуспешные challenges (стейки)
- Swap fees (0.684% creator portion от Bankr)

Расходуется:
- Rewards за успешные challenges
- Периодический buyback + burn
- Operational costs

## Запуск токена

**Платформа:** Bankr (@bankrbot в Twitter)
**Сеть:** Base (Ethereum L2)
**Механика:** тегаешь @bankrbot с параметрами → ERC-20 + Uniswap V3 пул мгновенно

**Timeline:**
- День 0-2: бот работает без токена (proof-of-content)
- День 3-5: набор 200-500 фолловеров
- День 5-7: запуск $BEEF через Bankr
- День 7+: включение burn-to-roast

## Отличия от мёртвых конкурентов

| Фактор | $BULLY (мёртв) | $ROAST (мёртв) | $BEEF |
|--------|----------------|----------------|-------|
| Roast bot | Да | Да | Да |
| Token utility | Нет | Нет | Burn-to-roast |
| Accountability | Нет | Нет | Challenge voting |
| Autonomous content | Частично | Частично | 60-70% контента |
| Deflation mechanism | Нет | Нет | Каждый запрос = burn |

$BULLY и $ROAST умерли потому что токен был просто мемкоин без utility. $BEEF — utility token с механической deflation.

## MVP scope (что запускаем первым)

**Включено в MVP:**
- Автономные роасты (5/день)
- Reply на mentions (20-30/день)
- Fact-checker (Claude Haiku pre-publish)
- Content filter (TOS compliance)
- Image-card генерация (для viral sharing)

**НЕ включено в MVP (Phase 2):**
- Burn-to-roast (после запуска токена)
- Challenge/voting (после стабильной аудитории)
- Wallet roast ("roast my portfolio")
- Farcaster integration
